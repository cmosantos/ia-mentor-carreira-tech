# IA Mentor de Carreira: Descubra Seu Futuro em Tech

Projeto curto desenvolvido para desafio da DIO, com o objetivo de simular um mentor de carreira com inteligência artificial para ajudar pessoas iniciantes a descobrirem possíveis caminhos na área de tecnologia.

A aplicação faz perguntas simples sobre interesses profissionais e sugere uma trilha de carreira em tech, como Suporte Técnico, Cloud Computing, Dados, Inteligência Artificial, Cibersegurança, Desenvolvimento ou DevOps.

## Objetivo do projeto

Criar uma aplicação web simples, educativa e interativa que demonstre como a IA pode apoiar decisões de carreira, orientação profissional e desenvolvimento de habilidades na área de tecnologia.

## Funcionalidades

- Formulário com perguntas sobre perfil e interesses.
- Sugestão automática de área em tecnologia.
- Explicação curta sobre a trilha recomendada.
- Lista de habilidades iniciais para estudar.
- Interface simples e responsiva.
- Projeto feito com HTML, CSS e JavaScript puro.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Responda às perguntas e clique em **Descobrir minha trilha**.
